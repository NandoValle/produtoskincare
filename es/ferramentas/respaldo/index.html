Respaldo de tus datos

Tu tracker, tus fotos y tus notas viven solo en este dispositivo: eso es lo que garantiza la privacidad. Este archivo es el paracaídas: exporta un respaldo de vez en cuando y guárdalo en lugar seguro. Si cambias de navegador o borras datos, es él quien trae todo de vuelta.

Exportar respaldo

Genera un archivo .json con el tracker de rutina, el diario de fotos y las observaciones de este dispositivo.

Importar respaldo

Restaura los datos de un archivo exportado por esta herramienta. Los datos actuales de este navegador serán reemplazados.

Privacidad: ningún dato sale de aquí sin ti. El archivo se genera en tu navegador y se descarga a tu carpeta de descargas: el sitio nunca lo recibe.

Preguntas frecuentes

¿Cómo hago un respaldo de mi tracker de rutina y mi diario de fotos?

Usa la opción de exportar, que genera un archivo .json con el tracker de rutina, el diario de fotos y las observaciones de este dispositivo. Guárdalo en lugar seguro. Importar restaura los datos y reemplaza los actuales de este navegador.

¿El archivo de respaldo de skincare se envía al sitio?

No. El archivo se genera en tu navegador y se descarga a tu carpeta de descargas: el sitio nunca lo recibe. Respaldo significa aquí un archivo .json que funciona como paracaídas si cambias de navegador o borras datos.
