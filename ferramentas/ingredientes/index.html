Verificador de ingredientes

Cole a lista de ingredientes dos seus produtos e descubra se há conflitos entre ativos.

Como usar: Cole a lista de ingredientes (INCI) ou os nomes dos ativos principais. Separe por vírgula ou quebra de linha. Ex: "retinol, ácido salicílico, vitamina C"

Quer saber mais de cada ativo? Veja as fichas de ingredientes, com o nível de evidência e as fontes.

Conflitos conhecidos

  • Retinol + Ácidos (BHA/AHA) → muita irritação. Alterne dias.
  • Retinol + Vitamina C → pHs incompatíveis. Use C de manhã, retinol à noite.
  • Retinol + Peróxido de benzoila → inativa o retinol.
  • Vitamina C + Niacinamida → ✅ PODE usar juntos (mito que não pode).
  • Ácido hialurônico + qualquer ativo → ✅ Compatível com tudo.
Não é aconselhamento médico. Em caso de irritação, pare o uso e consulte um dermatologista.
